## 2. Solution analytique — Taylor-Green 2D

La solution Taylor-Green 2D satisfait Navier-Stokes **exactement** pour tout Re (terme source nul) :

```
u(x,y,t) = -sin(πx) × cos(πy) × exp(-2π²t/Re)
v(x,y,t) =  cos(πx) × sin(πy) × exp(-2π²t/Re)
p(x,y,t) = -(cos(2πx)+cos(2πy))/4 × exp(-4π²t/Re)
```

Vérification de l'équilibre NS :

```
∂u/∂t = -2π²u/Re
(u·∇)u = -π sin(2πx)/2 × exp(-4π²t/Re)   [composante x]
-∇p    = +π sin(2πx)/2 × exp(-4π²t/Re)   [composante x]
→ (u·∇)u + ∇p = 0
→ ∂u/∂t = (1/Re)Δu   ✓
```

L'advection est exactement compensée par le gradient de pression. L'erreur de discrétisation mesurée est bien l'erreur spatiale du solveur discret.

### Isolation de l'erreur spatiale

Avec dt=1e-4 fixe entre toutes les grilles :
- L'erreur temporelle O(dt) = O(1e-4) est **la même pour toutes les grilles**
- Elle ne diminue pas avec le raffinement → n'affecte pas l'ordre mesuré
- L'ordre de Richardson mesure uniquement l'ordre spatial

Ratio erreur temporelle / erreur spatiale sur grille 64 :
```
ε_t / ε_s ≈ O(dt) / O(dx²_64) = 1e-4 / (1/64)² = 1e-4 / 2.44e-4 ≈ 0.41
```
Non négligeable en valeur absolue, mais **fixe entre les grilles** → l'ordre Richardson est bien l'ordre spatial.

## 8. Limites honnêtes

1. **Grille 128×128 non testée.** 5000 pas × 128² ≈ 82M opérations = trop long pour CI. L'extrapolation depuis 16→32→64 est cohérente mais non mesurée.

2. **Terme source = 0.** La solution Taylor-Green satisfait NS exactement. Une MMS avec terme source forcé (solution non physique mais avec terme source calculé) permettrait de tester d'autres formes de la solution et de garantir que l'implémentation des termes sources est correcte — chantier OPEN.

3. **Erreur temporelle non négligeable en valeur absolue (ratio ≈ 0.41).** Fixe entre grilles → n'affecte pas l'ordre. Mais la valeur absolue de L2 contient une contribution O(dt) ≈ 0.41 × ε_spatiale.

4. **Splitting Chorin CL/pression.** L'erreur de splitting introduit un terme O(dt) sur les bords — présent et fixe. Ne perturbe pas l'ordre mais limite la précision absolue.

5. **Régime turbulent (Re > 1000) : hors périmètre.** Les schémas centrés 2ème ordre ne sont pas upwind-stabilisés. À Re très élevé, instabilités probables.
