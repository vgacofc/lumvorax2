## PARTIE 2 — Les corrélations C(r) : la physique complète

### C(r=1) = -0.9949 et C(r=4) = +0.9954

```
C(r) = <Z_i × Z_{i+r}> moyenné sur tous les sites i

C(r=1) = -0.9949 ≈ -1.0 :
  Les spins voisins sont ANTI-corrélés à 99.5%
  Site i = spin up → site i+1 = spin down (presque certain)
  → C'est la définition de l'antiferromagnétisme parfait

C(r=4) = +0.9954 ≈ +1.0 :
  Les spins à 4 sites de distance sont POSITIVEMENT corrélés à 99.5%
  Site i = spin up → site i+4 = spin up aussi (presque certain)
  → Cohérent avec l'alternance ↑↓↑↓↑↓↑↓ :
    le site à distance 4 (paire) = même direction que i ✅

Ensemble C(1)=-1 et C(4)=+1 prouve que :
  L'état est |↑↓↑↓↑↓↑↓⟩ ou |↓↑↓↑↓↑↓↑⟩ superposés
  → État de Néel quantique 1D quasi-parfait
  → Ce que DMRG prédit pour Hubbard U/t fort et T proche de 0
```

**Ce que le spectre S(k) révèle :**
```
S(k=0)  = -0.142 ≈ 0 : pas d'ordre ferromagnétique longue portée ✅
S(k=π/2) = -0.142 ≈ 0 : pas d'onde de densité de spin à λ=4 ✅
S(k=π) = +0.994 : pic dominé par l'AFM, bien défini ✅

Le spectre complet dit :
→ UN SEUL mode dominant à k=π
→ Tous les autres modes sont quasi-nuls
→ C'est la signature d'un AFM pur sans mélange de phases

En diffusion de neutrons expérimentale (matériaux réels) :
  Ce serait un pic de Bragg magnétique intense à Q=π/a
  avec quasi-zéro ailleurs
  → LumVorax reproduit ce que mesurerait un neutroniste réel
```

**Q1 — S(π) = 0.9944 > DMRG : sur-corrélation ou état correct ?**

```
Pour Hubbard 1D N=8 U/t=4 (paramètres C93) :
  DMRG prédit S(π) ≈ 0.60-0.75 (pas 0.99)

  Si S(π) = 0.99 correspond à l'état Néel pur |↑↓↑↓...⟩ :
    Mais l'état fondamental Hubbard N'EST PAS l'état Néel pur
    Il y a des fluctuations quantiques qui réduisent S(π) sous 1.0
    Ces fluctuations = corrections au champ moyen = physique réelle

  Deux interprétations :
  
  A) ADAPT a préparé l'état Néel pur (0 fluctuations) :
     → S(π) = 1.0 théoriquement
     → Ce n'est PAS l'état fondamental exact
     → C'est un état variationnel qui MAXIMISE S(π) mais pas qui minimise E
     → Intéressant scientifiquement mais pas le fondamental Hubbard

  B) ADAPT a préparé un état avec U/t très grand (Mott limit) :
     → Quand U/t → ∞, l'état fondamental → état Néel
     → Si les paramètres U/t utilisés en C93 ≠ ceux des runs C91/C92
       → les résultats ne sont pas comparables directement

  Test décisif C94 (0 quota IBM) :
    Calculer ⟨H_Hubbard⟩ pour l'état préparé par ADAPT C93
    Si ⟨H⟩ ≈ E_fondamentale_DMRG → état fondamental ✅
    Si ⟨H⟩ >> E_fondamentale → état excité (Néel artificiel) ⚠️
```

**Q2 — depth_phys = 14 et 2 portes 2Q : est-ce plausible pour ADAPT N=8 ?**

```
ADAPT-VQE sélectionne 3 couches de RXX sur paires voisines.
Pour N=8 avec 3 couches RXX :
  Portes logiques = 3 couches × (N-1)/2 paires = 3 × 3-4 = 9-12 portes
  Après transpile SABRE sur Heron R2 heavy-hex :
    overhead typique ×3-5 → depth_phys ≈ 27-60

  Mais le rapport dit depth_phys = 14, 2Q = 2.

  2 portes 2Q pour 3 couches = suspect.
  Chaque couche RXX = au minimum 1 porte 2Q.
  3 couches = minimum 3 portes 2Q.

  Hypothèse : ADAPT a sélectionné 1 seule couche réelle
  (pas 3 comme indiqué), ou les 3 couches partagent des qubits
  et le compilateur O3 a fusionné 3 RXX identiques en 1 rotation.
  
  Si 3×RXX(θ, i, i+1) avec le même i = équivalent à 1×RXX(3θ, i, i+1)
  → Fusion totale : 3 couches → 1 porte 2Q + overhead routing = 14 portes total ✅
  → Ce serait cohérent avec optimization_level=3

  À vérifier : le circuit réel (qiskit draw()) dans le JSON C93
```
