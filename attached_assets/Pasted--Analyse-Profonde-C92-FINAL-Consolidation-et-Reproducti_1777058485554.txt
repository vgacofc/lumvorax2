```

  + ZNE corrige mieux sur circuit plus "régulier" (profondeur croissante linéaire)

Résultat : à N=16, l'effet statistique domine l'effet bruit
→ La mesure est plus précise à grande taille qu'à petite taille
→ Excellent signe pour le scaling C93 vers N=24/32
```

```

Round 1 :
  → Optimisation golden section depuis θ initial
  → Calcule stability (qualité de la solution)
  → Si stability ≥ 0.90 → STOP (état propre, pas besoin de plus)
  → Si stability < 0.30 → re-randomisation perturbée

Round 2-5 (si nécessaire) :
  → Nouveau point de départ = meilleur précédent + bruit gaussien σ=0.1 rad
  → Re-optimisation depuis ce nouveau point
  → Garde la meilleure solution de tous les rounds

Analogie :
  Chercher le point le plus bas dans un paysage montagneux avec brouillard
  Round 1 : descendre depuis la position initiale → vallée locale
  Round 2 : téléporter légèrement → explorer si une vallée plus profonde existe
  Round 3-5 : idem jusqu'à satisfaction
```

### La courbure 5-points : pourquoi c'est important

```
3-points (C91) : d²E/dθ² ≈ (E(θ+ε) - 2E(θ) + E(θ-ε)) / ε²
  Erreur = O(ε²) ≈ 0.01 pour ε=0.1

5-points (C92) : coefficients (-1, 16, -30, 16, -1) / 12
  d²E/dθ² ≈ (-E(θ+2ε) + 16E(θ+ε) - 30E(θ) + 16E(θ-ε) - E(θ-2ε)) / (12ε²)
  Erreur = O(ε⁴) ≈ 0.0001 pour ε=0.1

Amélioration : facteur 100× sur la précision de la courbure

Pourquoi la courbure est importante ?
  Courbure > 0 : minimum (vallée) → solution stable
  Courbure < 0 : maximum (sommet) → solution instable
  Courbure ≈ 0 : point selle → ambigu, module "instable"

Avec 5-points :
  → is_pure_physics (stab > 0.90) détecté avec précision 0.01%
  → is_unstable (stab < 0.30) détecté sans faux positifs
  → 1000× moins d'erreur de classification des modules
```

## PARTIE 3 — HVA S(π) : pourquoi 0.35 au lieu de 0.55 (DMRG)

### L'ansatz n_rep=1 est le goulot d'étranglement

```
HVA n_rep = nombre de "couches" du circuit variationnel
  n_rep=1 : 1 couche → profondeur logique ~30 → depth_phys ~149 pour N=16
  n_rep=6 : 6 couches → profondeur logique ~180 → depth_phys ~600-900 pour N=16

Pourquoi plus de couches = meilleur signal ?
  Chaque couche = 1 "étape" d'optimisation variationnelle
  n_rep=1 : l'ansatz peut décrire des corrélations à 1 voisin
  n_rep=6 : l'ansatz peut décrire des corrélations à 6 voisins
  DMRG : corrélations arbitrairement longues → valeur exacte

Analogie :
  n_rep=1 : photographier un tableau avec 30cm de recul
  n_rep=6 : photographier avec 1.8m de recul → plus de détails visibles
  DMRG : image à résolution infinie

S(π)_observé / S(π)_DMRG ≈ 0.35/0.55 = 0.64 → manque 36%
Ce 36% est encodé dans les corrélations longue-portée
que n_rep=1 ne peut pas capturer.
```
