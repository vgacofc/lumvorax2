# 1. Clarification physique fondamentale

## 1.1 « Antiferromagnétisme détecté » — sens exact

Dans le modèle de Hubbard Model, les électrons interagissent via :

* hopping (t)
* interaction locale (U)

Quand (U/t) est élevé → les spins s’organisent en alternance :

```
↑ ↓ ↑ ↓ ↑ ↓
```

👉 C’est ça l’**antiferromagnétisme (AFM)**.

---

## 1.2 Ce que mesure exactement S(π)

C’est une corrélation spin–spin :

[
S(\pi) = \frac{1}{N} \sum_{i,j} (-1)^{i-j} \langle S_i S_j \rangle
]

👉 Si S(π) > 0 :

* spins alternés corrélés
* ordre AFM présent

---

## 1.3 Traduction de tes résultats

* S(π) ≈ 0.30 → 0.36
* attendu exact ≈ 0.5+

👉 Donc :

| Interprétation                      | Statut |
| ----------------------------------- | ------ |
| corrélations AFM présentes          | ✅      |
| ordre correct qualitativement       | ✅      |
| amplitude correcte quantitativement | ❌      |
