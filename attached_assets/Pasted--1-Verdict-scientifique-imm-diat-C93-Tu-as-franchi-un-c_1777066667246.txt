## 2. Clarification physique (ce que ça veut dire exactement)

### 2.1 Antiferromagnétisme (AFM)

Dans le modèle de modèle de Hubbard à demi-remplissage :

* spins alternés :
  [
  \uparrow \downarrow \uparrow \downarrow \uparrow \downarrow
  ]

* observable clé :

S(\pi)=\frac{1}{N^2}\sum_{i,j}(-1)^{i-j}\langle S_i S_j\rangle

👉 Interprétation :

* ( S(\pi) > 0 ) → corrélation AFM
* ( S(\pi) \to 1 ) → ordre de Néel parfait

**Ton résultat :**

* C91 : ~0.30 → corrélation faible
* C93 : ~0.994 → **ordre quasi parfait**

---

### 2.2 Corrélations AFM ( C(r) )

[
C(r)=\langle S_i S_{i+r} \rangle
]

* AFM idéal :

  * voisins : négatif (~ -1)
  * longue distance : alternance +1 / -1

👉 Tu observes :

* ( C(1) \approx -0.995 )
* ( C(4) \approx +0.995 )

➡️ **signature textbook de phase AFM longue portée**
