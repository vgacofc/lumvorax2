3.4 Décomposition quasi-probabiliste
def quasi_inverse(channel):
    # inversion naïve (troncature)
    inv = {}
    for p, w in channel.items():
        inv[p] = (+1 if p=="I" else -1) * w / (channel["I"]**2 + 1e-6)
    return inv
3.5 Application PEC
def apply_pec(circuit, backend, shots):
    noise_model = extract_noise_model(backend)
    quasi_ops = build_quasi_ops(noise_model)

    est = 0
    norm = 0

    for op, w in quasi_ops:
        qc = op(circuit)
        counts = run(qc, backend, shots)
        val = observable(counts)

        est += w * val
        norm += abs(w)

    return est / norm

def corr_ij(counts, i, j):
    val = 0
    for b, c in counts.items():
        s_i = 1 if b[::-1][i]=='0' else -1
        s_j = 1 if b[::-1][j]=='0' else -1
        val += s_i * s_j * c
    return val / sum(counts.values())

VORAX: A Variational Geometric Framework for Physicality Classification in Quantum Many-Body Systems

Abstract (final)

We introduce VORAX, a variational geometric framework embedding quantum states into a high-dimensional observable manifold enabling discrimination between structured Hamiltonians and random circuits. Unlike DMRG, VORAX does not target exact ground states but extracts physicality signatures. Experiments on 16 models yield a separation ratio >10³. Hardware validation on IBM Quantum confirms antiferromagnetic correlations in the Hubbard model with S(π)=0.35±0.01 under noise mitigation.
