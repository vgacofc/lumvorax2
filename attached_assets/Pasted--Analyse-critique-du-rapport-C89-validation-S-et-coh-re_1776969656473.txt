## Analyse critique du rapport C89 — validation S(π) et cohérence mathématique

### 1. Résumé du résultat C89

Le rapport affirme essentiellement trois points :

* correction de la formule de facteur de structure ( S(\pi) )
* apparition d’un **offset massif (~+1.15 à +1.19)** dans les résultats C84–C88
* conclusion : tous les anciens résultats seraient des artefacts, et le signal AFM serait nul

Sur le plan méthodologique, l’approche C89 (double mesure legacy vs corrigée + validation statevector) est correcte.
Mais **l’interprétation quantitative contient plusieurs incohérences majeures**.

---

## 2. Vérification mathématique du “bug fondamental”

### 2.1 Contribution diagonale

Le rapport affirme :

> inclusion des termes ( i = j ) → offset ≈ +1

Correction réelle :

* terme diagonal : ( Z_i Z_i = 1 )
* somme diagonale : ( \sum_i 1 = N = 8 )
* normalisation C89 : ( N(N-1) = 56 )

Donc contribution exacte :

[
\frac{8}{56} = 0.142857...
]

➡️ **Effet diagonal seul ≈ +0.143**, pas +1.0

---

### 2.2 Incohérence majeure sur l’offset total (~+1.19)

Le rapport observe :

* legacy ≈ 1.17
* corrected ≈ 0.02
* différence ≈ 1.15–1.19

Ce résultat **ne peut pas être expliqué uniquement par :**

* inclusion diagonale
* changement de normalisation ( /N \rightarrow /N(N-1) )

Même en combinant :

* diagonal (+0.143)
* rescaling factor (×(N-1)=7)

on obtient un effet de l’ordre de :

[
0.143 + O(1)
]

mais **pas un offset constant ~1.2 indépendant du circuit**

➡️ Conclusion : **le bug est plus profond que décrit**

---

## 3. Diagnostic probable du vrai problème

Les symptômes décrits sont typiques de l’un des cas suivants :

### (A) Double normalisation implicite (très probable)

Exemples classiques :

* division déjà appliquée dans `counts → p = c/n`
* puis renormalisation globale
* puis redivision dans boucle finale

➡️ cela crée un facteur artificiel proche de (N) ou (N(N-1))

---

### (B) Mélange de conventions d’observables

Le code mélange probablement :

* définition spin ( n_i = 1 - 2b_i )
* et corrélation brute de bitstrings
* avec un facteur ((-1)^{i-j})

➡️ ce mix peut introduire un **shift constant non physique**

---

### (C) Erreur structurelle plus critique : biais de base distribution

Le fait que :

> S(π)_legacy ≈ 1.17 sur ibm_fez

suggère aussi un problème côté :

* normalisation des counts
* ou usage de quasi-distribution non normalisée
* ou agrégation multi-runs incohérente

---

## 4. Point critique : la conclusion “aucun signal AFM”

Le rapport conclut :

> S(π)_corrigé ≈ 0 ⇒ aucun signal AFM sur C84–C88

Cette conclusion est **trop forte**.

### Raisons :

1. **Le bruit hardware ibm_fez (~0.62 fidélité CNOT)** est dominant
2. Les circuits VORAX (depth 200–270 phys.) sont **hors régime cohérent**
3. Le calcul bitstring-based de ( S(\pi) ) est **très sensible au sampling noise**

➡️ Donc :

* S ≈ 0 peut signifier :

  * absence de signal
  * ou destruction du signal par bruit

Ces deux cas ne sont pas distingués dans C89.

---

## 5. Problème conceptuel plus profond

Le rapport suppose implicitement :

> “S(π) bitstring = observable physique directe”

Or sur IBM Quantum hardware :

* S(π) estimé via sampling ≠ valeur observable exacte
* il dépend fortement :

  * du readout error
  * du layout transpiled
  * des corrélations de mesure

➡️ donc la comparaison C88 ↔ C89 mélange deux objets légèrement différents :

* estimator “théorique discret”
* estimator “sampling hardware bruité”

---

## 6. Ce que C89 démontre réellement (version corrigée)

Malgré les erreurs d’interprétation, C89 établit 3 résultats solides :

### 6.1 Le “record S(π) > 1” de C88 est non physique dans la définition corrigée

✔ validé

### 6.2 Les cycles C84–C88 ne sont pas directement comparables sans normalisation stricte

✔ validé

### 6.3 Le pipeline précédent contient une erreur systémique de définition observable

✔ validé

## 7. Ce que C89 ne démontre PAS

❌ absence totale de signal antiferromagnétique
❌ invalidation complète des expériences VORAX
❌ preuve que tous les résultats sont du “bruit pur”
❌ cohérence numérique du facteur d’offset (~1.19 non expliqué)

---

## 8. Conclusion technique

### Verdict sur C89

* **Méthodologie :** solide (double définition + validation ED)
* **Conclusion globale :** partiellement correcte mais sur-interprétée
* **Bug réel :** confirmé (définition S(π) incohérente)
* **Amplitude de correction :** mal estimée dans le rapport
