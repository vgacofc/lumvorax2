## Lecture critique du Cycle C98 et du cahier C99

Je vais être direct : **C98 est solide sur l’ingénierie**, mais **les conclusions implicites restent partiellement sur-interprétées**, surtout côté “performance” et “preuve”. C99 corrige bien la trajectoire, mais certains points doivent être verrouillés méthodologiquement avant publication.

---

# 1. Point fort réel de C98 (à conserver tel quel)

### ✔️ Couplage NX48 ↔ Izhikevich+STDP

C’est probablement **la contribution la plus originale du cycle** :

* Couplage **non destructif** (respect de la contrainte utilisateur)
* Signal borné → stabilité garantie
* STDP avec asymétrie 1.05 → cohérent biologiquement
* Injection “dopamine-like” → bon mapping heuristique

👉 Interprétation correcte :

> Tu as construit un **meta-contrôleur adaptatif bio-inspiré**, pas un simple “neurone”.

Ce point est **publiable** (section “heuristic hybrid control”).

---

### ✔️ Hook ASIC ↔ VORAX

C’est un vrai progrès architectural :

* Avant : silo
* Après : pipeline unifié via vecteur 8D

👉 Implication importante :

* Tu peux maintenant faire du **feedback matériel simulé → optimisation logique**
* C’est une base pour **co-design matériel/algorithme**

---

### ✔️ Record NX48 = 32 LZ

Attention ici.

✔️ Fait mesuré : oui
❌ Interprétation implicite : trop forte

Problème :

* Header factice
* Distribution non contrôlée
* Pas de baseline statistique

👉 Lecture correcte :

> “Observation d’un événement rare dans un espace non calibré”

PAS :

> “amélioration prouvée du mining”

---

# 2. Problème critique (non corrigé dans C98)

## ❗ Absence de baseline statistique

Tu mesures :

* 32 LZ (1 run)
* amélioration loss

Mais tu n’as PAS :

* distribution sur 100+ runs
* comparaison random search
* comparaison heuristique simple

👉 Donc :

**Tu ne sais pas si NX48 (ou le coupleur) apporte réellement quelque chose.**

---

# 3. Analyse du couplage neuro — point technique

### Ce qui marche

* Mapping feature → neurone : cohérent
* STDP full mesh : expressif
* EMA rate : bon choix

### Ce qui manque

1. **Décorrélation des entrées**

Actuellement :

* 8 features → 8 neurones (1:1)

➡️ Problème :
corrélations fortes → réseau peu informatif

👉 Correction C99 recommandée :

```c
input_i = Σ_j W_ij * features[j]
```

---

2. **Saturation du régime RS**

Tu observes :

* ~63 Hz

Mais :

* régime RS optimal ~20–40 Hz

➡️ Tu es en sur-stimulation

👉 Effet :

* perte de dynamique STDP
* signal moins informatif

---

3. **Signal global trop compressé**

```c
mod ∈ [-1, +1]
```

Puis :

```c
exploration_bias *= (1 + 0.15 * mod)
```

➡️ Impact max ≈ ±15 %

👉 C’est faible → effet potentiellement noyé dans le bruit NX48
