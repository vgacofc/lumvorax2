# 🔬 2. ANALYSE PHYSIQUE — CE QUI EST VRAIMENT IMPORTANT

## 🟢 (A) Pattern `00001111` — interprétation correcte mais incomplète

Tu dis :

> antiferromagnétique / ordre de charge

✔️ plausible
❗ mais attention :

### problème critique

Ce pattern peut aussi venir de :

* biais de lecture (readout bias)
* mapping qubits physiques → logiques
* transpilation (layout IBM)

👉 Donc :

### correction rigoureuse

Il faut vérifier :

```
P(00001111) - P(bit-flipped equivalent)
```

et surtout :

* symétrie gauche/droite
* invariance sous permutation de qubits

👉 sinon → faux positif physique possible

---

## 🟢 (B) Pattern 6Q `111100` / `100101`

✔️ là c’est plus crédible physiquement :

* espace plus petit
* entropie plus basse (~3 bits)
* dominance plus forte (~40%)

👉 signal > bruit

### mais encore :

tu dois vérifier :

* corrélations 2-corps :

  ```
  ⟨Z_i Z_j⟩
  ```

👉 sinon tu vois juste un motif, pas une phase physique
