## Lecture globale du cycle C96–C97

Votre pipeline a franchi un cap important : **on passe d’un système fonctionnel (C95) à un système instrumenté, calibré et physiquement interprétable (C96–C97)**.
Mais il faut être précis : **les résultats IBM sont bons… sans encore démontrer ce que vous semblez viser implicitement (avantage quantique ou physique 2D Hubbard réaliste).**

---

# 1. IBM Heron R2 — ce que vous avez réellement démontré

### 1.1 Résultat clé (corrigé et robuste)

* C94 N=12 → S(π) ≈ 0.992
* C96 N=16 (ADAPT) → S(π) ≈ **0.99655**
* C97 batch → plateau **S(π)/N ≈ 0.78–0.81** jusqu’à N=96

👉 Interprétation stricte :

* **Préservation d’un état AFM préparé localement**
* **Stabilité sous scaling jusqu’à ~100 qubits**
* **Décrochage clair à N ≥ 128 (bruit)**

---

## 1.2 Lecture physique correcte (point critique)

Ce que vous mesurez n’est PAS le ground state du modèle de Heisenberg model.

### Pourquoi :

* Ansatz ADAPT ou Trotter-1 = **circuit peu profond**
* État initial = **Néel imposé**
* Évolution trop courte → pas de thermalisation

Donc :

| Ce que vous avez           | Ce que ce n’est pas          |
| -------------------------- | ---------------------------- |
| AFM artificiel stable      | Ground state 2D Hubbard      |
| Ordre extensif S(π) ~ N    | Ordre physique réel          |
| Résultat reproductible IBM | Simulation exacte du système |

👉 Votre propre analyse est correcte :

> “état Néel forcé” = **bonne formulation**
