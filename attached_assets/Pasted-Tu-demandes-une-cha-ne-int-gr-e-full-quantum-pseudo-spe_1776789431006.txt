# 2. 🔬 Pseudo-spectrum via Krylov (Qiskit réaliste)

## Objectif

Approximer :
\sigma_\epsilon(A)={z\in\mathbb{C}:|(A-zI)^{-1}|>\epsilon^{-1}}

## Implémentation réaliste

### Méthode utilisable sur IBM Quantum :

* Krylov subspace (Arnoldi-like)
* Estimation via circuits Trotterisés
* Mesure de projection d’état

### Structure code (Qiskit)

```python
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator
import numpy as np

def krylov_step(U, psi, k):
    states = [psi]
    for i in range(k):
        psi = U @ psi
        states.append(psi)
    return np.array(states)

def pseudospectrum_estimator(U, z_grid, eps):
    results = {}
    I = np.eye(U.shape[0])

    for z in z_grid:
        resolvent = np.linalg.inv(U - z*I)
        norm = np.linalg.norm(resolvent, 2)
        results[z] = norm > 1/eps

    return results
```

👉 Sur IBM réel :

* U vient d’un **Hamiltonien Trotterisé**
* Norme estimée via sampling probabiliste (NOT exact inverse)

# 4. 🧭 NX-ATOM feedback vers transpiler (dynamic routing)

## Ce qui est réaliste :

IBM transpiler permet :

* coupling map
* routing optimization
* layout pass

### Ton “NX-ATOM feedback” devient :

## boucle adaptative :

```
run circuit → collect error metrics → adjust layout → re-transpile
```

### pseudo-implémentation :

```python
def nx_atom_feedback(transpiled_circuit, backend_properties):
    error_map = backend_properties.gate_error_rates
    best_qubits = sorted(error_map, key=error_map.get)

    return best_qubits
```

👉 C’est un **heuristic optimizer**, pas un accès hardware direct.

# 5. 🔥 Hubbard model (HTS coupling)

Hamiltonien :

H = -t \sum_{\langle i,j \rangle,\sigma} c^\dagger_{i\sigma}c_{j\sigma} + U \sum_i n_{i\uparrow}n_{i\downarrow}

## Implémentation Qiskit

* Jordan-Wigner transform
* Trotter decomposition
* time evolution circuit

```python
from qiskit.opflow import PauliSumOp

def build_hubbard(n_sites, t, U):
    # placeholder structure
    return PauliSumOp.from_list([
        ("ZIZI", t),
        ("ZZII", U)
    ])
```

👉 Réalité :

* approximation forte obligatoire
* scaling exponentiel sinon

# 6. 📊 Spectral reconstruction (post IBM run)

```python
def reconstruct_spectrum(counts):
    spectrum = {}
    for state, freq in counts.items():
        energy = int(state, 2)
        spectrum[energy] = freq
    return spectrum
```
